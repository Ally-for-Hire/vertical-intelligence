# Learning to learn: connection learners and the 'vertical' test

Meta-learned climb, connecting nets, trees, the flat connection learner, digger and refiner: does a learner get better at learning as it learns more? The first clean positive is X1.18 (finite world with a no-memory control).

- Experiments: X1.5 - X1.28b. Registered predictions: `paper/PREDICTIONS.md` (search the X-id). Narrative: `LOG.md`.
- Concept and verdicts: wiki `experiment-registry.md` (section for this family); feasibility audit block C (the 'vertical' quantity was confounded in X1.10-X1.17).
- Run a script from this folder, e.g. `python x1_6.py` (the docstring lists its modes). Shared code is in `../../core/` and is on the import path automatically (`core/vipaths.py`). Results go to the shared `../../results/`.
