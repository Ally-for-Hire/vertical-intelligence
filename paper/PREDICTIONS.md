## X7.3 A Self with a life goal over as many sensors as we can give it (author's request 2026-10-29: "take as much input as we can give it ... some goal in life, to be informative, helpful, correct ... takes everything in the world and analyzes it"; loop iteration 1; `vi/x7_3.py`; idea I17), registered 2026-10-29 BEFORE any run (scored seeds 73000-73047 = 48 worlds; nothing tuned; W&B run 'X7.3 | A Self with a goal over many sensors')
