A 120-generation smoke test showed effective complexity growing 3 -> 64 under the "prediction does not drop" rule by neutral drift alone.

## 2026-10-26 (later still) revision 13: lineage-improvement culling, pure-random refill
* Previous setting (cosine cull 0.15-0.5, blend-only refill, P=1000, 3000 gens, 187 s): ended with 1 lineage, 5% distinct functions, mean score 0.564, best 0.565; 2/24 solved at 90%+. Diversity collapse confirmed again (blend-only adds no variation).
* New (user): cull_rule 'improvement': each brain is scored on the same batch before and after its own self-modification each generation; lineage improvement = the running sum of those gains since the brain was born; bottom 50% by lineage improvement are culled each generation; every empty slot is refilled with a brand-new random brain (a new lineage). Interpretation choices made by the assistant (flagged): "improvement" = cumulative same-batch own-modification gain (not raw score, not birth-to-now score, which would reward unlucky births via regression to the mean); "bottom 50%" = fixed 50% (cull_min = cull_max = 0.5; the wave remains available). Because every brain is its own lineage, 'effective lineages' is ~P by construction and is no longer informative; distinct functions and score are the real variety measures.
* Early observation (first 225 generations, P=1000): mean score 0.453 (random baseline 0.451), best 0.538, hidden nodes 32 avg: no upward trend yet. Expected risk: selecting on improvement alone does not select for absolute score, and constant replacement of half the population by random brains limits accumulation. ## 2026-10-26 revision 15: near-copy culling ("dedupe")
User: "we need enough variation to continue improving, maybe we cull any brains that are within some threshold of each other, replace with random". Implemented in multi_big.py (default ON, --no_dedupe switches off; previous revision multi_big_v15_snapshot.py): each generation every brain's deterministic answers on the fixed 24-problem probe set (768 rows) are compared; a brain that has a BETTER-ranked brain within distance eps (fraction of probe answers that differ) is culled in addition to the performance cull and replaced with a fresh random brain. eps has no free parameter: it is the smallest distance between any two brains of a fresh random population of the same size (0.1914 at P=1000).
Measured in the improvement-rule/fresh-refill regime (P=1000, 120 generations): only 0-1 near-copies per generation, i.e. the rule is almost inert here, because with pure-random refill every brain is already functionally distinct (100% distinct functions, 1000 lineages). The rule matters in regimes where the population converges (rank by raw score with copy/variation/blend refill, which collapsed to 1 lineage, 5-8% distinct functions); not yet run there. The 15%-cull, no-dedupe run emerge1k_improve15_s0 was stopped at about generation 600 (mean score 0.455, random baseline 0.451).

## 2026-10-26 why every run plateaus at ~0.56-0.6 (diagnosis; selfscore/ceiling.py, diagnostic run diag_minT2_wave1000_s0)
Observation (user): scores rise sharply for ~100 generations and then stop; "if it was working as intended we should see consistent growth".
Evidence: (1) gradient-trained reference models on the same inputs (task code included): shared linear = 0.549 mean accuracy, 1/24 problems at 90%+ (this is exactly the function class of a T=1 brain, because hidden nodes cannot influence the output at T=1); separate linear classifier per problem = 0.762, 12/24; shared MLP (32 or 128 hidden units) = 0.973, 22-23/24. The plateau of the evolved brains (0.56-0.61, 1/24) equals the shared-linear ceiling. (2) In every wave/blend run the population's mean T drops from 2.0 to 1.0 within ~50 generations (hidden nodes then keep growing to the 96 cap as inert, neutral baggage) and the population collapses to 1-2 lineages by generation ~100-400. (3) Diagnostic (--min_T 2, evolution may not choose T=1; same wave/blend settings, P=1000, 3000 gens): plateau rises to ~0.62-0.645 (above the linear ceiling) but still stalls at 2/24 solved and 1 lineage. The speed pass is not the cause: the pre-optimisation code gave T=1.0, 92 hidden nodes and 0.594 at generation 300.
Conclusion: two search defects, not a bug in the arithmetic: (a) selection removes depth (T) because depth is not rewarded until several coordinated weights are right (XOR/parity need >= 2 hidden units: a fitness valley), and (b) the population loses its variation before any such circuit can be found. Candidate fixes (not applied): keep depth alive (T floor or deterministic hidden nodes), protect innovations (speciation/lineage niches, near-copy culling, islands), and cull so that variation is retained.

## 2026-10-26 revision 18: "everything random" foundation + sliding-window percentile death + survival score (user)
User: "the foundation is the problem. something isn't random. we want EVERY SINGLE VARIABLE TO BE ENTIRELY RANDOM, including structure"; "the bottom 15% percentile of score ALL die, regardless of count of population... imagine a sliding window"; "scoring based on how many cullings they survive". Choices confirmed by the user in a question: population size fixed (dead replaced), cutoff from recent history, randomness = structure + mechanism genes.
* Pop2.random_brains (pop2.py; previous pop2_v12_snapshot.py): every new brain draws its number of hidden nodes (0-30) and their slots, edge density (log-uniform 0.5%-30%), every edge (any node -> any non-input node), weight scale (log-uniform 0.1-3.2), biases, every node's activation type, T in 1..6, beta (0.25-8), mutation step size (0.02-1), mutation count (0.3-4) and every operator probability (random, no prior). Only the ranges are fixed. Used for the starting population and every refill (--hand_init restores the old start).
* cull_rule 'percentile' (multi_big.py; previous multi_big_v18_snapshot.py): each generation a window length W is drawn at random in 1..min(history, 100); the cutoff is the 15th percentile of all scores of the last W generations; EVERY brain at or below it dies (ties included), however many that is; the dead are replaced by entirely random brains. Interpretation (assistant, flagged): death is decided by accuracy against that cutoff; a brain's SCORE is the number of cullings it has survived (ranking deaths by survival count itself would make every newborn the bottom and kill them all each generation). The single best brain is spared if everyone would die.
* Test (P=500, 60 gens): deaths vary 37-120 per generation (7-24%), oldest brain 60 cullings, mean accuracy 0.46 (random 0.451). Full run pct15_random_s0 (P=1000, 3000 gens) launched.
