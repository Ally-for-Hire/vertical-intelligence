# Prediction-only life and boredom

An entity whose whole existence is prediction and internal models; how exact must its boredom be.

- Experiments: X1.3, X1.4. Registered predictions: `paper/PREDICTIONS.md` (search the X-id). Narrative: `LOG.md`.
- Concept and verdicts: wiki `experiment-registry.md` (section for this family); findings-map section 0 / drives.
- Run a script from this folder, e.g. `python x1_3.py` (the docstring lists its modes). Shared code is in `../../core/` and is on the import path automatically (`core/vipaths.py`). Results go to the shared `../../results/`.

| Experiment | Script | Result files in `results/` |
|---|---|---|
| X1.3 | `x1_3.py` | `x1_3_check.json`, `x1_3_run.json` |
| X1.4 | `x1_4.py` | `x1_4_run.json`, `x1_4_tune.json`, `x1_4_tune.log` |
