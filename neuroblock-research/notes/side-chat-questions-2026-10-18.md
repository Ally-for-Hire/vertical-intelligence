# Side chat: questions for working backwards from the end result (2026-10-18)

Returned by a background agent started from a side chat about working backwards from the end result, with questions from
brain-related professions that the earlier list (systems engineering, neuroscience, cognitive psychology, IFS clinical work,
development, ML, measurement theory, epistemology) had left out. Saved here unedited so the questions are not lost.
When answering, say which assumptions are fixed givens and which are claims you want the experiments to test.

**Neurologist / neuropsychologist (damage and dissociation)**
1. When a region is damaged, one ability can vanish while others stay intact. What does losing a "part" look like in your system, and should the rest keep working?
2. In split-brain patients, each hemisphere can act as if it were a separate agent. Is that evidence for your parts model, or a different phenomenon?
3. Some patients explain actions they never chose (confabulation). Does your Self report on the parts accurately, or build a story afterwards?

**Psychiatrist (what goes wrong)**
4. What does a malfunction look like: a part that won't stop firing, a part that can't be reached, or a Self that can't coordinate? Which should the simulator be able to produce?
5. Does the system have a stable healthy state, or only moves toward and away from one?

**Anesthesiologist / sleep researcher (changing the state)**
6. Under anesthesia and in deep sleep the brain is still active but no experience is reported. Is "expressed" the same as "active", or does expression need something more?
7. Dreams recombine parts without the Self steering. Should the system have an offline mode that runs parts with no input?

**Memory researcher**
8. Recalling a memory seems to rebuild it, and the rebuilt version is stored again. Does that match "no state until observed"? Does each recall change the part?
9. Forgetting: is it deletion, or a part that can no longer be reached?

**Neuroanatomist / network scientist**
10. Does the brain's physical layout determine which parts can talk, or is the layout something the parts create? The simulator lets neurons move, so which is intended?
11. Is the structure hierarchical, flat, or small-world? What would you expect the shortest path between two parts to look like?

**Information theorist**
12. What is the unit of information passing between parts: a signal, a prediction, or a request? What is lost when the Self summarizes?
13. How much of the system's state can an observer read out? If "unobserved" means "unread", then the readout is the interface.

**Complexity / dynamical-systems scientist**
14. Is the system meant to settle into stable states (attractors), stay near the edge of chaos, or keep wandering?
15. What would count as the system "evolving" rather than just changing?

**Philosopher of consciousness**
16. Does the system need anything it is like to be it, or is functional behavior enough for the end result? Decide now so the experiments don't have to.
17. Is the Self a separate part, an emergent summary, or the observer itself?

**Ethologist / evolutionary biologist**
18. What was each part originally for, and what did it cost to keep it? The "effort" cost is a cost of that kind.
19. Do parts compete, cooperate, or both? What decides which?

**Linguist**
20. If a problem is converted into the system's own representation, is that representation shared between parts or private to each? Does it need to be translatable back to words?

**Statistician (for meeting in the middle)**
21. For each foundational theory, what result in the simulator would count as confirming it, and what would count as refuting it? Decide before running anything, so every result can be scored.
