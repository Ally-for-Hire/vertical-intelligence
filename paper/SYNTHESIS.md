## 2. What this means for the Dream (a better transformer), stated as proposals

Each surviving principle suggests a change to how a transformer learns. None has been tested on a transformer yet.

1. **A wiring budget.** Add L1 or sparsity pressure on connections; it improved generalisation here.
2. **Explicit context inference with verification.** Route to specialists, and query or verify when routing confidence is low; do not average. Best trigger found: disagreement among retrieved memories (an episodic index next to the specialists), both when learning and when answering (CTX6/7, R); plus shocks (CTX9-11); plus a meta-level choice between recognition methods judged by predictive track record (CTX12b).
3. **A block library.** Persist reused sub-computations across problems; the gain grows with depth and with shared structure.
4. **Motivation plus a learnability filter** for self-directed data selection (active learning or curriculum).
5. **A teacher curriculum** from simple to complex compositions.
6. **Eligibility-trace credit** for delayed feedback.
7. **A focused world model** for acting: model only goal-relevant variables.

## 3. Biggest open problems

- Context inference from errors alone (the Self's core job). Every self-run variant failed; check-when-unsure is the first partial answer, and at TEST time it is now solved in this world by memory (episodic) recognition + checking where memories disagree (CTX6, R). Learning-time context is also solved here by asking where memories disagree (CTX7, R: parts 2.59 -> 1.12 x oracle, end-to-end 1.29 x). New open question: why a more ACCURATE unsupervised routing (memory vote, 7% vs 48% misroutes) gave no better parts CTX8 measured it (R): confident misroutes land on parts that badly mispredict the point and do 40-46 x more damage per tick, so being wrong RARELY but CONFIDENTLY is worse than being wrong often but harmlessly. Principle: judge an assignment by how surprising the point is to the part receiving it, not only by how sure the router is. CTX9 used it as a SURPRISE GATE with no questions: parts ~1.45 x oracle (from 2.3-3.0 x), about 70-75% of the way to asking (S; thresholds fragile on replication). Questions on shocks are slightly better than on disagreements at equal counts (3-7%; CTX10 corrected an earlier '3 x' overstatement), but shocks are scarce; both triggers together give essentially perfect parts (1.02 x oracle) with ~7% questions (CTX9c + CTX10, R). TRANSFER (CTX11c, S): when context is TIME, not place, shock-triggered asking still gives near-oracle error (1.03 x, corrected scoring) with 0.34% questions; the input-similarity recogniser does not transfer; and context that is wrong 14% of the time is worse than no context at all. A META-recogniser that trusts whichever recognition method has been predicting better lately (judged by consequences, not by agreement with labels) matches the right method in both place and time worlds (CTX12b, S: one fresh seed set). The full stack with one setting for both worlds reaches 1.20 x (place) and 1.14 x (time) of perfect context knowledge on fresh seeds (CTX13); generality costs ~10% in the time world against a time-specialised stack.
