# vi/: vertical-intelligence experiment plan code

`w0.py` the shared world W0 (`python w0.py` = self-check). `learner.py` the shared gradient-descent learner. `x0_1.py` experiment X0.1 (`python x0_1.py pilot|tune|run`, results in `../results/x0_1_*.json`). `x1_6.py` X1.6 (train the learning machinery on its ability to increase held structure; `python x1_6.py selftest|run|log`). `x1_47.py` X1.47, the linear base rung of that ladder and a mastery gate (in and out of range; `python x1_47.py selftest|run`). `winf.py` THE WORLD: use `make_finite_world(seed, FINITE)` (X1.18: fixed finite library, then one expansion; the expanding `make_world` of X1.17 is VOID by author ruling). `wstream.py` open-ended world, finite at every moment, `expand(n)` on request, `save`/`load` replay bit-exactly (saved worlds: `../worlds/`). `flat.py` THE BASE LEARNER (X1.15; `flat.Learner` = step-wise): flat connection learner, use `cfg=flat.OPT`; `x1_15.py parity|tune|run` reproduces its tuning. `constants.py` registry of every number; `python audit.py` must print 0 undeclared. Plan and results: Knowledge-Wiki `domains/vertical-intelligence/wiki/experiment-plan.md`, `findings-map.md`.

## Run control (`ctl.py`)
`python core/ctl.py status|ping|stop|start|restart [x1_29 ...]` - process state, CPU/RAM, progress (`results/<name>_progress.json`), log age, result present. Stop kills only that experiment's process tree. x1_29 caches each finished world (`results/x1_29_worlds/`), so `restart` resumes. `_watch.sh` is the health watcher (stall / dead / traceback / low RAM / finished).

**Digger input selection (2026-11-03):** default `pick="rand"` = all 60 labels random. Choosing inputs is optional: `pick="mix"` (20 random + 40 where its own halves disagree most) or `pick="auto"` (learn the problem both ways, keep the better = the optional evolution). Older results (X1.28/28b) used mix; their scripts set it explicitly.
