# Value and the self; drives

Does value defined through the agent's own needs give need-dependent valence, safety, attention to every need and a hidden need only depth can satisfy? Includes the first curiosity drives (learning progress, optimism, noisy-TV and dark-room controls).

- Experiments: X0.1 - X0.10, X1.1, X1.2. Registered predictions: `paper/PREDICTIONS.md` (search the X-id). Narrative: `LOG.md`.
- Concept and verdicts: wiki `experiment-registry.md` (section for this family); findings-map section 0.
- Run a script from this folder, e.g. `python x0_1.py` (the docstring lists its modes). Shared code is in `../../core/` and is on the import path automatically (`core/vipaths.py`). Results go to the shared `../../results/`.
