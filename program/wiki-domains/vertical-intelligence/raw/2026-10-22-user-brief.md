# Curious-net: user brief (2026-10-22, paraphrased from voice dictation, kept close to original)

Build, in line with the neuroblock-research ideas, an algorithm applicable to ANY problem with inputs and outputs.

- Boolean on/off neurons. A SELF-EXPANDING number of neurons is the core concept.
- Main drive: ELIMINATE UNCERTAINTY. Goal: try to connect everything in its environment with everything else.
- Test example: a car that moves forward and turns left/right continuously, navigating various tracks.
- It should expand as needed with information given; it should be CURIOUS, run its OWN EXPERIMENTS, work out what actually affects things.
- Senses: binary grid-of-tiles view of the board (car moves continuously over the grid) PLUS access to all environment variables (wheel drag coefficient, forward momentum, ...).
- Base level is Boolean 1/0; it continuously changes its own circumstances to understand the world; as understanding grows, performance should directly improve. "A curious neural network."
- Core feature: arbitrarily many unrelated / independent variables; each tested individually; dependent variables not forgotten.
- Sensors form a continuous stream with readable HISTORY, converted directly into Boolean representations and continuously PREDICTED.
- PRIMARY goal: reduce uncertainty in its existence. SECONDARY (hidden) goal: maximize score = stay in the middle of the path and move at full speed.
- It knows what is scored, but its drive is uncertainty reduction; HIDDEN goal monitored and adjusted until a full algorithm: infinite inputs, infinitely growing neurons, arbitrary outputs. "Learn literally everything it can to pass a test."
- Primary theory: in the drive for understanding it builds enough world understanding to apply to the task.
- Process asks: ask Fable 5.1 for implementation plan / ideas / questions (minimum for a small working model); keep user continuously and completely in the loop; write theorems and test them; provide graphics and papers; start a log in the Knowledge Wiki so work can be resumed any time.
