# Contributor portal

A small web page (one FastAPI process, one HTML file, phone-first) that lets people the author
has given a key read this repository, ask grounded questions about it, and propose experiments
into `contrib/queue/`. It reads the repo on disk and re-indexes when `HEAD` changes. Answers and
drafts are generated by Claude Sonnet through the **author's Anthropic API key** (Developer
Platform), not a claude.ai subscription. The portal **never runs experiments**: proposals are
queued, and the author registers and runs them under the research protocol.

## Setup (from the repo root)
```
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -r portal/requirements.txt
set ANTHROPIC_API_KEY=sk-ant-...  # Linux/macOS: export ANTHROPIC_API_KEY=...
python portal/app.py                # or: python -m uvicorn portal.app:app --host 127.0.0.1 --port 8765
```
Open http://127.0.0.1:8765 and paste a key.

## Keys
```
python portal/keys.py new --name alice --budget 300000 --daily 60000   # shown once
python portal/keys.py list
python portal/keys.py usage
python portal/keys.py revoke alice            # by name or id
```

## Exposing it
`cloudflared tunnel --url http://127.0.0.1:8765` prints a public URL. Only bind `0.0.0.0` when
a tunnel or reverse proxy fronts it. On a phone, open the tunnel URL and use "Add to Home Screen".

## Deploying on a dedicated server later
Run the same command (`python portal/app.py`; `PORTAL_HOST`/`PORTAL_PORT` set the bind address) under a process manager (systemd on Linux, NSSM on Windows), set
`PORTAL_REPO` to the clone path, and keep binding to `127.0.0.1` behind the tunnel/reverse proxy.

## Environment variables
| Variable | Meaning |
|---|---|
| `ANTHROPIC_API_KEY` | The author's API key (required for Ask and Propose) |
| `PORTAL_MODEL` | Model id (allow-listed to Sonnet) |
| `PORTAL_GLOBAL_DAILY_TOKENS` | Cap on all keys together per day |
| `PORTAL_RATE_PER_MIN` | Requests per minute per key |
| `PORTAL_MAX_QUESTION_CHARS` | Longest accepted question |
| `PORTAL_GIT_PULL` | `1` = `git pull --ff-only` on each poll |
| `PORTAL_GIT_PUSH` | `1` = push after committing a proposal (default: commit only) |
| `PORTAL_POLL_SECONDS` | How often to check `HEAD` (default 60) |
| `PORTAL_REPO` | Path of the repo clone to serve |

## Cost
Budgets are enforced in tokens (input + output), which the API reports exactly. Check current
Sonnet pricing on the Anthropic pricing page before choosing budgets.

## Data
Keys (hashed), usage and logs live in `portal/data/` (gitignored). Never commit it.
