# The Self, sensors and doubt

A Self that audits networks from the inside, learns when not to answer, creates and reuses routines, plus closed-form checks of the combined model.

- Experiments: X7.1 - X7.7b, X8.0 - X8.1e. Registered predictions: `paper/PREDICTIONS.md` (search the X-id). Narrative: `LOG.md`.
- Concept and verdicts: wiki `experiment-registry.md` (section for this family); findings-map Self and doubt sections.
- Run a script from this folder, e.g. `python x7_1.py` (the docstring lists its modes). Shared code is in `../../core/` and is on the import path automatically (`core/vipaths.py`). Results go to the shared `../../results/`.
